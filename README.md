# 公務活動報名系統 練習站（Vibe Coding 網頁資安實測教材用）

這個練習站「故意」留有弱點，供課堂上讓學員練習攻擊與判讀。所有帳號、姓名、電話、金鑰都是虛構的。
請勿放入任何真實資料；課程結束後請把服務關閉。

## 運作方式

- 學員只需要瀏覽器，不必安裝任何軟體。
- 每位訪客有自己專屬的一份測試資料（留言、報名狀態、對話），互不影響；資料存在記憶體，服務重啟就會清空。
- 橫幅右邊的按鈕可在「未修補版（紅色）」與「已修補版（綠色）」之間切換，只影響自己。
- 「AI 服務問答」是規則式模擬，不是真的語言模型，只認得教材裡的測試提示詞。

## 部署到 Render

1. 把本資料夾的 `app.py`、`requirements.txt` 放進一個 GitHub 儲存庫。
2. 在 Render Dashboard 選 New → Web Service，連結該儲存庫。
3. 設定：
   - Language：Python 3
   - Build Command：`pip install -r requirements.txt`
   - Start Command：`python app.py`
   - Instance Type：Free 即可
   - Health Check Path（選填）：`/healthz`
4. （選用）在 Environment 新增 `CLASS_CODE`，值為課程通行碼；設定後，學員第一次進站要先輸入通行碼。
5. 部署完成後取得網址（`https://名稱.onrender.com`），填進簡報「課前準備(1)：開啟練習站」的網址框。

注意事項：

- 程式會讀取 Render 提供的 `PORT` 環境變數並綁定 `0.0.0.0`，不需要另外設定。
- Free 方案閒置 15 分鐘會休眠，下一次開啟要等一分鐘左右；上課前請先自己開一次網址。
- 需要 Python 3.8 以上，不使用任何第三方套件。
- 課程結束後，到 Render 把服務 Suspend 或刪除。

## 在自己電腦執行（備課用）

```
python app.py
```

瀏覽器開啟 http://localhost:8000 。8000 埠被占用時加上 `--port 8001`。

|---|---|---|---|

## 截圖怎麼取得（共 22 張）

1. 開啟練習站，依下表的「模式」切換版本，照「操作」做到指定的畫面。
2. 按 Win + Shift + S，框選整個瀏覽器視窗（要包含網址列）。
3. 回到簡報對應的頁面按 Ctrl + V 貼上，縮放到灰色虛線框的大小。
4. 在圖片上按右鍵 →「移到最下層」，預先放好的紅框與紅色編號就會浮在圖片上面。
5. 刪除灰色提示框，把紅框與編號拖到「標示」欄寫的位置。
